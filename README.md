# flntools

A monorepo of two projects, each in its own folder.

- `flnd/`: a downloader that saves whole accounts from the web. See [flnd/README.md](flnd/README.md).
- `flni/`: an incremental desktop game, in planning. See [flni/PLAN.md](flni/PLAN.md).

Each folder is its own uv project: run `make` inside it.
